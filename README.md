# Peppa Party

To-do list, shopping list and run of show for a Peppa Pig themed 3rd birthday —
pool session, craft table, pancake dinner, chocolate cake with piped grass.

Single self-contained page. Tick state and headcount live in the browser
(localStorage). Quantities scale from the kids/adults steppers at the top.

**Live:** https://smcktown.github.io/peppa-party/
